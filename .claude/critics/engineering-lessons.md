# Engineering critic lessons

- 2026-11-16 — A guard that keeps names out of a public repo checks commit messages, file paths and every local branch, not only staged content.
- 2026-11-16 — Rebuilding a tool that is live in the user's own config happens in a worktree, with a switch-over after validation, never by editing it in place.
- 2026-11-16 — A public repo that learns from private work keeps that feedback in a local overlay, never in tracked files.
